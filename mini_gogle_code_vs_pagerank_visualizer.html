Under The Hood

Code Relevance vs. PageRank Algorithm

Early search engines relied solely on lexical matching (counting words in HTML/code). Modern search engines combine content relevance with graph-based link analysis.

On-Page Lexical Scoring

Code & Content Analysis (TF-IDF / BM25)

Evaluates what a page says by tokenizing HTML tags, titles, headings, and body text. Term Frequency–Inverse Document Frequency rewards rare query words that appear frequently on a page.

tfidf_scorer.js O(V + E_terms) 
function computeCodeScore(queryTerms, doc, corpus) {
  return queryTerms.reduce((score, term) => {
    // Term Frequency (with title boost)
    const tf = (doc.termFreq[term] || 0) / doc.wordCount;
    const titleBoost = doc.title.includes(term) ? 2.0 : 1.0;
    // Inverse Document Frequency
    const docsWithTerm = corpus.filter(d => d.termFreq[term] > 0).length;
    const idf = Math.log((corpus.length + 1) / (docsWithTerm + 1)) + 1;
    return score + (tf * idf * titleBoost);
  }, 0);
}
Off-Page Graph Authority

PageRank Algorithm (Power Iteration)

Evaluates who trusts the page by modeling the web as a directed graph. A hyperlink from page u to page v acts as a weighted vote proportional to u's own importance.

pagerank.js PR(v) = (1-d)/N + d · Σ PR(u)/L(u) 
function iteratePageRank(nodes, edges, d = 0.85) {
  const N = nodes.length;
  const nextPR = {};
  nodes.forEach(v => {
    let inboundSum = 0;
    edges.filter(e => e.target === v.id).forEach(e => {
      const u = nodes.find(n => n.id === e.source);
      const outDegree = edges.filter(x => x.source === u.id).length;
      inboundSum += u.pr / outDegree;
    });
    nextPR[v.id] = (1 - d) / N + d * inboundSum;
  });
  return nextPR;
}
Dimension Code / Content Relevance (TF-IDF) PageRank (Graph Authority)
Core Principle Lexical similarity between user query tokens and document HTML/text. Random surfer probability distribution across the web's hyperlink graph.
Query Dependence Query-Dependent — Computed dynamically per search query. Query-Independent — Pre-computed offline across the crawl graph.
Primary Strength Pinpoints exact terminology, code snippets, and topical specificity. Surfaces trustworthy, authoritative, and widely cited sources automatically.
Key Vulnerability Easily manipulated by keyword stuffing and hidden spam text. Vulnerable to link farms, paid backlinks, and cold-start for new pages.
Modern Search Role Candidate retrieval & semantic matching (paired with neural embeddings). Core trust & authority signal used to re-rank retrieved candidates.
